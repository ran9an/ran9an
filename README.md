## 🚀 About This Repository

This repository hosts the source code for my interactive personal portfolio website.

### 🗂️ Project Structure
```text
Portfolio - Ranjan Jena/
├── assets/
│   ├── css/            # Style sheets (Bootstrap, FontAwesome, Themes)
│   ├── js/             # Interactive scripts (GSAP, WOW.js, Odometer, OwlCarousel)
│   ├── img/            # Media, icons, hero assets & showcase images
│   └── fonts/          # Custom typography and icon fonts
├── index.html          # Main landing page & portfolio showcase
├── blog.html           # Blog listings & insights
├── blog-details.html   # Detailed article view
└── README.md           # Repository overview & profile documentation
```

### 💻 Local Preview
To run the portfolio locally on your machine:
```bash
# Clone the repository
git clone https://github.com/resourcereloaded/portfolio.git

# Navigate into the project folder
cd portfolio

# Open index.html in your default browser (or use Live Server in VS Code)
start index.html
```
